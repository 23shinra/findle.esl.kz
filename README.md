# Findle — текст → WhatsApp / Instagram / Telegram / email / ссылки

## Как пользоваться

1. Открой приложение в браузере (локально или на сервере).
2. Вставь текст в поле (Ctrl+V).
3. Ниже появятся кнопки быстрых действий.

> Кнопка «Вставить из буфера» (Clipboard API) не работает при открытии файла как `file://`. Используй локальный сервер или развёрнутый сайт.

## Запуск (Node.js, рекомендуется)

Статические файлы лежат в папке `public/`, API и SQLite — в `server.js` и `data/`.

```bash
npm install
npm run dev
```

Открой `http://localhost:5173`. Для продакшена: `NODE_ENV=production npm start` (порт и хост задаются переменными `PORT` и `HOST`, см. `.env.example`).

## Переменные окружения

Скопируй `.env.example` в `.env` и при необходимости задай:

- `FINDLE_ADMIN_SECRET` — если задан (не короче 8 символов), включается `GET /api/inputs` для выгрузки записей; передай тот же секрет в заголовке `X-Findle-Admin` или `Authorization: Bearer …`. Без секрета список **отключён** (безопаснее для публичного сайта).

## Что парсится

- **Телефон**: 7–15 цифр, варианты с `+`.
- **Instagram**: `@username`, ссылки `instagram.com/…`, `ig.me/m/…`.
- **Telegram**: `@username`, `t.me/…`.
- **Email** и **URL** по обычным эвристикам.

## Прочее
